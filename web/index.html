Method

What this captures

Local conversation history retained by four agent tools. A prompt record is a user-message candidate after identifiable tool results, automatic notifications and subagent instructions are excluded. Copied fork history can remain. This is a snapshot, not a complete lifetime account export.

Charts count retained records, including repeated requests. The archive combines identical text within an app and shows how many occurrences it had. Word counts include pasted code and context, measured before redaction.

How the text is cleaned

Known injected wrappers are removed. GLiNER2 detects sensitive spans locally; deterministic rules remove credentials, contact details, URLs and local paths. Additional opaque token-like strings are masked. Some harmless terms may also be replaced.

Only the cleaned publication dataset is hosted here. Raw logs, original prompts, account identifiers and processing API keys stay out of the site.

How the buckets work

Jev labels the underlying purpose of cleaned prompts using neighboring requests and known project goals. Immediate task, domain, interaction and requested autonomy are recorded separately. These are automated interpretations, not a measure of success. Long prompts may use a head-and-tail excerpt for classification; the archive keeps the cleaned full text.

“Execute” describes requested action; it does not prove that action succeeded. Different apps retain different telemetry, so unavailable tokens and turns are shown as unavailable.

Sources, definitions and processing checks

Cleaning model: Fastino GLiNER2 privacy filter. Classification: TypeSafe Jev. The pilot covered 300 real prompts and 32 synthetic cases. All 52 known synthetic sensitive spans were covered by the combined model and rules. Those challenge results are not a real-world accuracy estimate.
